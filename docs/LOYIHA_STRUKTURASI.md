# ANDTI Talent Hub: loyiha strukturasi

> Andijon davlat texnika instituti iqtidorli talabalarini bir joyga jamlovchi, ularni kashf qiluvchi, rivojlantiruvchi va imkoniyatlarga ulovchi platforma.

---

## 1. Missiya va asosiy g'oya

**Missiya:** har bir talabaning iqtidorini ko'rinadigan, o'lchanadigan va qadrlanadigan qilish.

Platforma uch tsikl asosida ishlaydi:

```
   KASHF QILISH  ──────►  RIVOJLANTIRISH  ──────►  IMKONIYATGA ULASH
 (AI, challenge,         (AI mentor, kvest,       (grant, ish, freelance,
  o'qituvchi tavsiyasi)   loyiha, mentorlik)       stipendiya, startup)
        ▲                                                  │
        └──────────── ball, daraja, e'tirof ◄──────────────┘
```

Har bir harakat ball beradi. Ball darajani oshiradi, daraja esa yangi imkoniyatlarni ochadi. Natijada talaba qaytib kelishga motivatsiya oladi.

## 3. Modullar: birlashtirilgan struktura

Avvalgi barcha g'oyalar **8 ta asosiy modulga** birlashtirildi. Har bir funksiya qaysi versiyaga kirishi belgilangan: **MVP** (birinchi 2 oy), **v2** (3–6 oy), **v3** (6–12 oy).

### Modul 1. 🧬 Talent Passport (iqtidor profili)
Talabaning raqamli iqtidor portreti.

| Funksiya | Versiya |
|---|---|
| Profil: fakultet, kurs, qiziqishlar, bio, havolalar (GitHub, LinkedIn) | MVP |
| Yutuqlar: olimpiada, sertifikat, maqola, sport, ijod (hujjat yuklash bilan) | MVP |
| Ko'nikmalar xaritasi (radar diagramma) | MVP |

| HEMIS integratsiyasi: baholar avtomatik | v2 |
| AI rezyume va portfolio sayt (`talent.andti.uz/ism`) | v2 |
| QR bilan tekshiriladigan raqamli sertifikatlar | v2 |
| Raqamli talaba ID | v3 |

### Modul 2. 🔍 Discovery (iqtidorni kashf qilish)
Yashirin iqtidorlarni topish tizimi.

| Funksiya | Versiya |
|---|---|

| O'qituvchi «uchqun» belgisi: iqtidorni qo'lda belgilash | MVP |
| AI iqtidor tahlili: faollik, natija va dinamikadan «yashirin iqtidor» signali | v2 |
| «Kelajakdagi men»: mos kasblar, maosh oralig'i, yetishmayotgan ko'nikmalar | v2 |

### Modul 3. 🎓 Growth (rivojlanish)
Talabani o'stiruvchi vositalar.

## 4. Ball iqtisodiyoti

Platformaning «yuragi». Har bir modul ballar orqali bog'lanadi.

**Ball qanday topiladi (namuna):**

| Harakat | XP |
|---|---|
| Kunlik challenge | 10 |
| Haftalik challenge (yechim qabul qilinsa) | 50 |
| Oylik challenge, top-3 | 300 |
| Tadbirda qatnashish (QR) | 20 |
| O'qituvchi tasdiqlagan ko'nikma | 30 |
| Loyiha bosqichini o'tish | 100 |
| Peer-to-peer dars berish | 40 |
| Olimpiada/hakaton g'olibligi (tasdiqlangan) | 500+ |
| 7 kunlik streak bonusi | 50 |

**Ikki xil valyuta:**
- **XP:** daraja va reyting uchun. Hech qachon kamaymaydi
- **Tanga (coin):** do'konda sarflanadi. XP bilan birga beriladi

**Tanga nimaga sarflanadi:** oshxona talonlari, kitoblar, merch, kurs sertifikatlari, konferensiya yo'llanmasi, rektor bilan uchrashuv.

**Real imtiyozlar (daraja asosida):** rektor stipendiyasi, xorijiy almashinuv va mini-grant tanlovlarida qo'shimcha ball.

**Firibgarlikdan himoya:** yirik yutuqlarni o'qituvchi tasdiqlaydi, kunlik ball limiti bor, challenge yechimlari plagiatga tekshiriladi.

## 5. Talaba yo'li (user journey)

```
1. Telegram'dan kirish (1 daqiqa)
      ↓
2. Onboarding: qiziqishlar, 3 ta savol → AI boshlang'ich yo'l xaritasi beradi
      ↓
3. Birinchi kunlik challenge → birinchi nishon 🎉 (birinchi 5 daqiqada «wow»)
      ↓
4. Profilni to'ldiradi → ko'nikmalar xaritasi paydo bo'ladi
      ↓
5. Kvest yoki loyihaga qo'shiladi → jamoa topadi
      ↓
6. Daraja oshadi → yangi imkoniyatlar ochiladi (freelance, grant)
      ↓
7. Natija: stajirovka / grant / startup / ish taklifi
      ↓
8. Bitiruvchi → mentor bo'lib qaytadi (tsikl yopiladi)
```

### Texnologiyalar steki

| Qatlam | Texnologiya | Sabab |
|---|---|---|
| Frontend | Next.js, TypeScript, Tailwind, shadcn/ui | Tez, SEO (portfolio sahifalar), mobilga mos |
| Telegram | Mini App (shu Next.js kodi) + aiogram bot (Python) | Talabalar Telegram'da |
| Backend | Python, Django, Django REST Framework | Tayyor admin panel, xavfsizlik, tez ishlab chiqish |
| Baza | PostgreSQL + Django ORM | Ishonchli, relyatsion ma'lumotlar, avtomatik migratsiyalar |
| Kesh/navbat | Redis + Celery | Reytinglar, bildirishnomalar, fon vazifalari |
| AI | Claude API (anthropic Python SDK), pgvector (tavsiyalar uchun) | Ko'p tilli, kuchli tahlil |
| Fayllar | MinIO (S3 mos) | Sertifikat va rasmlar |
| Infra | Docker Compose → keyinchalik Kubernetes | Oddiy boshlash |
| CI/CD | GitHub Actions | Avtomatik test va deploy |
| Monitoring | Sentry, Grafana | Xatolar va yuklama |

**Shaxsiy ma'lumotlar:** O'zbekiston «Shaxsga doir ma'lumotlar to'g'risida»gi qonuniga muvofiq ma'lumotlar mahalliy serverda saqlanadi. AI'ga faqat zarur va anonimlashtirilgan ma'lumot yuboriladi.

## 7. Asosiy ma'lumotlar modeli

```
User (id, role, telegram_id, ism, fakultet_id, kurs, til)
 ├── Profile (bio, qiziqishlar, havolalar, avatar)
 ├── Skill ←→ UserSkill (daraja, tasdiqlagan_oqituvchi_id)
 ├── Achievement (turi, nomi, hujjat, holat: kutilmoqda/tasdiqlangan)
 ├── XpTransaction (miqdor, sabab, manba_id)  → reyting shundan hisoblanadi
 ├── CoinTransaction
 ├── UserBadge ←→ Badge
 └── Streak

Faculty (nomi) ── League (semestr, ball)

Challenge (turi, qiyinlik, muddat, xp) ── Submission (user, yechim, baho)
Quest ── QuestStep ── QuestProgress
Project (nomi, holat, tavsif) ── ProjectMember (user, rol)
Mentorship (mentor, talaba, holat) ── Meeting
Opportunity (turi: grant/vakansiya/olimpiada/freelance, hamkor_id, muddat)
 └── Application (user, holat)
Partner (korxona, kontakt)
Reward (nomi, narx_coin, zaxira) ── Redemption
Post ── Comment ── Like
Event ── EventAttendance (QR skanerlash)
Club ── ClubMember
AiConversation ── AiMessage
Notification
```

## 9. Yo'l xaritasi

| Bosqich | Muddat | Natija |
|---|---|---|
| **0. Tayyorgarlik** | 2–3 hafta | Rektorat bilan kelishuv, 20–30 talaba bilan suhbat, jamoa, dizayn prototipi |
| **1. MVP** | 6–8 hafta | Telegram kirish, profil, challenge, XP/daraja/badge/streak, reyting, AI mentor, lenta, tadbirlar QR, imkoniyatlar, do'kon, dashboard |
| **2. Pilot** | 4 hafta | 1–2 fakultetda sinov, **Launch Hackathon**, fikr-mulohaza yig'ish |
| **3. v2** | 3–4 oy | HEMIS, AI rezyume, AI tahlil, kvestlar, mentorlik, jamoa topish, liga, freelance, grantlar, klublar |
| **4. To'liq joriy** | — | Butun institut, korxonalar bilan shartnomalar |
| **5. v3 va kengayish** | 6–12 oy | Lab band qilish, ixtiro reestri, AI intervyu, bashoratli tahlil, boshqa OTMlar uchun SaaS |
